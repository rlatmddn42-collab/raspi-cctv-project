Write a handoff text document for continuing this work later.

This document is not limited to a single project. Review the current context and identify all active projects, workstreams, documents, codebases, prompts, experiments, or unfinished tasks. If there are multiple separate items, organize them separately.

The purpose of this document is to preserve the current state so that another AI assistant, developer, or future session can continue from this point without needing the previous conversation.

Rules:
- Do not implement anything.
- Do not edit, delete, rename, or refactor files.
- Do not create new features.
- Do not assume everything belongs to one project.
- If something is uncertain, clearly mark it as uncertain.
- Focus only on analyzing the current state and writing a useful handoff document.

Please create the handoff document with the following structure:

# Handoff Document

## 1. Overall Context
- What has been worked on overall
- What the current workspace/session appears to contain
- Whether there are multiple separate projects or one unified project

## 2. Active Workstreams
For each detected workstream, write:
- Workstream name
- Purpose
- Current status
- What has already been decided
- What has already been done
- What remains unfinished
- Important constraints
- Risks or uncertain points
- Recommended next step

## 3. Existing Files and Artifacts
- Important files, folders, documents, prompts, drafts, or code modules
- What each one is for
- Whether each one is complete, partial, placeholder, outdated, or uncertain

## 4. Decisions Already Made
- Confirmed decisions that should be preserved
- Tentative assumptions that may need verification later
- Design, technical, structural, or writing-style decisions

## 5. Remaining TODOs
Group the remaining tasks into:
- Immediate next actions
- Medium-term tasks
- Later improvements
- Things to avoid for now

## 6. Constraints and Preferences
- Technical constraints
- Hardware/software assumptions
- UI/UX constraints
- Language/style constraints
- Performance constraints
- User preferences that affect future work

## 7. Open Questions
- What is still unclear
- What needs confirmation before major implementation
- What assumptions should be tested later

## 8. Continuation Summary
At the end, write a compact summary that can be pasted into a future AI session as context.

Write the document clearly, concretely, and practically. It should function as a real handoff note, not a casual summary.
