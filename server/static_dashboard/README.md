# 중앙 서버 대시보드 (정적 프로토타입)

이 폴더는 **외부 중앙 서버 측에서 동작**하는 운영자/관리자용
**메인 모니터링 대시보드** 프로토타입입니다.

라즈베리파이 로컬 디버그 UI가 아닙니다.

## 목적

- 여러 대의 라즈베리파이 엣지 디바이스에서 올라오는 결과를 통합 표시
- 실시간 CCTV 상태 모니터링
- 오염도 점수 / 온습도 / 이벤트 통합 조회
- 모델 버전, 서버 상태 점검

## 주요 섹션

- 실시간 CCTV 상태
- 오염도 현황
- 온습도 정보
- 이벤트 기록
- 설정

## 포함되는 카드/테이블

- CCTV 목록
- 장치별 오염도 점수
- 최근 이벤트
- 온도/습도 표시
- 서버 상태
- 모델 버전 정보

## 실행 방법

이 UI는 정적 HTML/CSS/JS 입니다. 별도의 빌드/서버가 필요 없습니다.

옵션 1: 파일을 직접 브라우저로 열기
- `index.html` 더블 클릭

옵션 2: 간단한 정적 서버
```
cd server/static_dashboard
python3 -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000` 접속.

## 현재 상태

- 백엔드 API 연동 없음
- 정적 placeholder 데이터만 표시
- 실제 학습 파이프라인 / 추론 결과 수집 / 모델 배포 연동은 추후 단계에서 구현
